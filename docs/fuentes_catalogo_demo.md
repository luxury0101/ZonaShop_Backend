# Fuentes de imágenes provisionales del catálogo

Las fotografías del comando `cargar_catalogo_demo` son recursos provisionales de Pexels, seleccionados sin modelos identificables ni logos visibles. Por defecto se descargan, recortan a 4:5, convierten a WebP y se almacenan mediante el storage configurado del backend. La opción `--enlaces-directos` conserva las URLs optimizadas de Pexels cuando no hay un token Blob válido.
